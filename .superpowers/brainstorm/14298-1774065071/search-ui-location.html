Where does the search live?

How do you invoke it and where do results appear?

A

Center-Stage Overlay (Cmd+K)

Replaces the current command palette. A floating modal in the center of the screen, like Raycast or Linear. Results stream in below the input. Dismisses on Escape or clicking outside.

Full-Page Search View

The search icon in the sidebar header opens a full-page search view that replaces the main content area (like ChatGPT's search). Results have room for rich previews, conversation excerpts, and document snippets side by side. Back button or Escape returns to the editor.
