How should the AI search work?

The search needs to handle both fast lookups and semantic questions. How should we balance speed vs intelligence?

A

Hybrid: Instant + AI

As you type, instant results appear immediately (title matches, keyword matches in content). Below them, an "Ask AI" section shows a shimmer/loading state and returns semantic results after ~1-2s. The AI results surface things like "Aiden mentioned this in chat on March 15" or "This concept appears across 3 documents."

Best of both worlds. Fast for simple lookups, smart for complex queries. The AI section only fires after a debounce (300ms pause in typing).

B

AI-First, Always

Every query goes through the AI. Type anything and the model interprets intent -- a single word like "pricing" returns relevant documents and conversations, a question like "where did we disagree?" returns contextual answers. No separate "instant" layer.

Simpler mental model (one search, always smart), but always has latency. Could feel sluggish for simple lookups.

C

Smart Routing

The system detects intent: short queries (<3 words) get instant local results only. Longer queries or questions (detected by "?" or natural language patterns) automatically trigger the AI search. No manual toggle -- it just knows.

Feels magical when it works. Risk: sometimes you want AI for a single word, or instant results for a long phrase.
