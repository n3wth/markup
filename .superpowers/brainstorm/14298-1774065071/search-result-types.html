What can you search for?

Beyond document titles -- what result types make this uniquely powerful for an AI-collaborative editor?

1

Document Titles

Basic but essential. Match session titles as you type. Already exists in sidebar -- this promotes it to the overlay.

2

Document Content

Full-text search across document bodies. Shows the matching passage with keyword highlighting and surrounding context. "Find the section about API rate limits."

3

Agent Conversations

Search across what agents said in chat. Filter by agent name. "What did Aiden say about the database schema?" Returns the specific message with agent avatar, timestamp, and link to jump into that session.

4

Agent Disagreements & Proposals

AI surfaces moments where agents pushed back, disagreed, or proposed changes. These are the highest-signal moments in a collaboration. "Show me where agents disagreed" or "Find rejected proposals."

5

Agent Edits & Changes

Search the actions agents took in the document -- insertions, replacements, structural changes. "Show me what Nova added to the PRD" or "Find all agent edits in this session."

6

Commands & Actions

Keep the existing command palette functionality -- new doc, toggle sidebar, download, etc. These appear below search results when relevant.
